# order-book
C++ Order Book implementation

🚧 Currently under development 🚧

## Dependencies
Ninja
```bash
sudo pacman -S ninja
```

CMake 3.20+
```bash
sudo pacman -S cmake
```

Clang
```bash
sudo pacman -S clang
```

## How to build
### Arch Linux
### Clone the project
```bash
git clone https://github.com/MateuszKuzniewski/order-book.git
```

### Build with CMake
```shell
cmake -S. -B build -G Ninja
cmake --build build
```

### Run 
```shell
./my_app
```
